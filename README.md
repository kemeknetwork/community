# KeMeK Community

The public discussion space for [KeMeK Network](https://kemek.com) — products,
services, and the people using them.

This repository holds no product source. It exists for one thing: a place to
ask, suggest, report, and hear back. Product source lives in private
repositories; **this is the front door.**

## Start here

| I want to… | Go to |
| --- | --- |
| Ask how something works, or get unstuck | [Q&A](https://github.com/kemeknetwork/community/discussions/categories/q-a) |
| Suggest a feature or a change | [Ideas](https://github.com/kemeknetwork/community/discussions/categories/ideas) |
| Show what I built with a KeMeK product | [Show and tell](https://github.com/kemeknetwork/community/discussions/categories/show-and-tell) |
| Talk about anything else | [General](https://github.com/kemeknetwork/community/discussions/categories/general) |
| Read release and status news | [Announcements](https://github.com/kemeknetwork/community/discussions/categories/announcements) |
| Report a mistake in *these documents* | [Issues](https://github.com/kemeknetwork/community/issues) — dead links, typos, wrong routing |
| Report a security vulnerability | [SECURITY.md](./SECURITY.md) — **never** a public discussion |
| Reach a human privately (billing, account, contracts) | [SUPPORT.md](./SUPPORT.md) |

New here? [CONTRIBUTING.md](./CONTRIBUTING.md) covers how to write a post that
gets a useful answer. [CODE_OF_CONDUCT.md](./CODE_OF_CONDUCT.md) covers how we
treat each other.

## What KeMeK is

Three brands, one network:

- **[kemek.com](https://kemek.com)** — the front door: free tools and apps,
  plus the consultancy serving small and mid-size businesses with technology,
  marketing, production, and operations.
- **[kemek.net](https://kemek.net)** — technology and infrastructure: domain
  names, web hosting, email, SSL, and the hosted platform.
- **[kemek.org](https://kemek.org)** — philanthropy: charitable initiatives
  and editorial content.

Anything under those three is on-topic here.

## What this repository is not

- **Not a product issue tracker.** Issues on this repository track defects in
  *these documents* — a dead link, a typo, routing that sends people to the
  wrong place. Anything about a KeMeK product is a discussion, not an issue.
  There is no triage SLA and no promise that a thread becomes a ticket. Good
  threads do influence what gets built — that is the point — but the roadmap is
  not decided here.
- **Not a support contract.** Paid customers with an account, billing, or
  contractual matter should use the private channels in
  [SUPPORT.md](./SUPPORT.md). Community answers are best-effort, from whoever
  shows up.
- **Not a source repository.** Nothing here is a KeMeK product. Pull requests
  are welcome only against the files in this repository — the community docs
  themselves.

## Response expectations

This space is maintained by a small team. Expect thoughtful answers rather than
fast ones. Announcements are written by maintainers; everything else is a
conversation, and the community answers as often as we do.

Threads that go quiet are not rejections. Bump them.
